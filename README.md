# Week 2 Day 2 Projects Overview

This repository contains Python projects based on functions, argument handling (args and kwargs), and related applications. The projects focus on building a solid foundation in Python function usage, including flexible input handling with positional and keyword arguments.

---

## Projects Overview

### Function Examples
- app.py  
  This script introduces the basics of Python functions including how to define, call, and return values from functions. It provides simple examples to help learners understand function scope, parameters, and return statements.

- chatbot.py  
  Implements a straightforward chatbot that interacts with the user through predefined function calls. This project showcases how functions can be used to modularize code and handle user input effectively.

---

### Argument Handling with args (Positional Arguments)
- movie_booking_input.py  
  Demonstrates the use of args to accept a variable number of positional arguments in functions. This example simulates a movie booking system where multiple seats or movie selections can be passed dynamically.

- order_app.py  
  Uses args to process orders with an unknown number of items. It illustrates how flexible argument lists can make functions adaptable to varying inputs without changing the function signature.

- parcel_dispatch.py  
  Illustrates handling of dispatch details through args, allowing the program to accept multiple package details in a single function call, enhancing scalability.

---

### Argument Handling with kwargs (Keyword Arguments)
- iot_config.py  
  Uses kwargs to configure IoT devices dynamically by passing named parameters. This approach makes the function flexible for a variety of configurations without hardcoding each possible parameter.

- social_scheduler.py  
  Implements scheduling features for social media posts, leveraging kwargs to allow users to specify different options like time, platform, and content, demonstrating flexible keyword argument usage.

- submit_exam.py  
  Processes exam submission data where students’ details and answers are passed as keyword arguments, showing how kwargs can help manage complex inputs cleanly.

---

### Assignment
- assignment.py  
  A practical exercise that reads a text file, counts the frequency of each word, and outputs the top 10 most frequent words. This script reinforces skills in file handling, string manipulation, and the use of collections for counting.

- sample.txt  
  A sample text file provided to test the word frequency script. It contains text data that the assignment.py script reads and analyzes.
