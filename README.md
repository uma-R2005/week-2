# Week 2 - Day 1 Projects

This day's projects focus on working with Python sets, dictionaries, and functional programming concepts. The aim is to strengthen your understanding of these fundamental data structures and operations by building practical examples.

## Projects on Sets in Python:

- email_filter.py – Demonstrates how to filter and clean email lists by removing duplicates and finding common or unique email addresses using set operations.
- inventory_management.py – Shows how sets can be utilized to manage inventory efficiently by tracking available, sold, and returned items.
- playlist_analysis.py – Uses sets to analyze music playlists, helping to identify common songs across playlists or unique tracks.

## Projects on Dictionaries in Python:

- finance_tracker.py – Implements a finance tracking system that uses dictionaries to store, update, and summarize income and expenses by categories.
- library_management.py – Builds a simple library management system where dictionaries store book details and track borrowing history.
- flight_booking.py – Manages flight reservations using dictionaries, enabling lookup, booking, and cancellation operations efficiently.

## Projects on Functional Programming Concepts:

- assignment.py – Provides standalone implementations of Python’s built-in `map()` and `filter()` functions using sets and dictionaries to reinforce functional programming principles.
